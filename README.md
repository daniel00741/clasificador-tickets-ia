# Clasificador de tickets con IA

Proyecto educativo para aprender AI Development construyendo un clasificador de tickets de soporte en Python.

## Objetivo

Recibir el texto de un ticket y devolver categoria, prioridad y justificacion en una estructura JSON validada.

Categorias iniciales: acceso, facturacion y tecnico.
Prioridades: baja, media y alta. Definiremos sus criterios antes de implementar el clasificador.

## Ruta de aprendizaje

1. Definir el problema, las reglas y ejemplos de tickets ficticios.
2. Preparar Python y el entorno de desarrollo.
3. Realizar la primera llamada a un modelo de lenguaje.
4. Disenar el prompt y validar la salida estructurada.
5. Evaluar resultados con casos conocidos y analizar errores.
6. Exponer el clasificador mediante una API.

## Metodo de trabajo

Cada etapa incluye explicacion, implementacion guiada y un ejercicio para el estudiante.
