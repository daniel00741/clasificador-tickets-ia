# Manual de soporte de la aplicación

## Restablecer una contraseña olvidada

Si olvidaste tu contraseña, selecciona "Olvidé mi contraseña"
en la pantalla de inicio de sesión.

Introduce el correo electrónico asociado a tu cuenta. Recibirás
un enlace para establecer una contraseña nueva.

Si no encuentras el correo, revisa la carpeta de spam.
Nunca compartas tu contraseña con soporte.

Este manual no especifica cuánto tiempo permanece válido
el enlace de restablecimiento.

## Cuenta bloqueada por intentos fallidos

Después de cinco intentos fallidos de inicio de sesión,
la cuenta se bloquea temporalmente durante quince minutos.

Espera ese período antes de volver a intentarlo.
Si olvidaste la contraseña, utiliza el procedimiento
de restablecimiento.

Si el bloqueo continúa después de ese período,
contacta con soporte.

Al contactar con soporte, indica el mensaje de bloqueo que aparece.

## Revisar un posible cobro duplicado

Si observas dos cargos por una misma suscripción,
comprueba si ambos están confirmados o si uno figura
como pendiente.

Para solicitar una revisión, proporciona a soporte
las fechas, los importes y las referencias de las transacciones.

Soporte debe verificar los cargos antes de confirmar
un reembolso.

Este manual no especifica el plazo de recepción
de un reembolso.

## Error al exportar un reporte

Si falla la exportación de un reporte, intenta exportar
un intervalo de fechas más pequeño.

Si el error continúa, registra el nombre del reporte,
el intervalo de fechas seleccionado y el mensaje de error.

Envía esa información a soporte para que investigue el fallo.
